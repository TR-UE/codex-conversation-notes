# 数据说明

墨记将用户选择导入的对话、正文编辑、高亮、批注、标签、删减历史和外观偏好保存在本机。图片快照也保存在本机。插件没有遥测、统计上报或批注云端同步。

导入本机聊天时，只读取用户指定编号的会话文件。原聊天文件不被改写；消息删减和编辑只作用于墨记副本。删除使用可恢复的本机记录，JSON 完整备份也包含这些记录，分享备份前请自行核对内容。

阅读面板仅监听回环地址。远程图片需要用户加载；导出时可尝试从原服务下载正文实际引用的公共图片，并保存快照。图片服务可能看到通常的网络请求信息，墨记不会把对话、批注、登录 Cookie 或账号凭据发送给图片服务。私网和本机下载目的地会被拒绝。

GitHub 仓库、安装包和演示只包含程序、说明与独立演示素材，不包含用户笔记数据库、会话文件、图片快照、机器配置或凭据。
