- 41 项 Python 回归测试：本机持久化、备份恢复、UTF-16 选区、并发冲突、正文编辑与锚点移动、撤销、同步不恢复删减、改名、图片快照与读取授权、SVG 清理、富格式 PDF / Word、原生批注与图片错误占位。
